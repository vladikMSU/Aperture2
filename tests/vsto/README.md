# Проверка жизненного цикла панели

Запуск из корня: `powershell -ExecutionPolicy Bypass -File scripts\test-vsto.ps1`.
Нужны Visual Studio MSBuild/Roslyn и targeting pack .NET Framework 4.8. Скрипт восстанавливает зависимость Newtonsoft.Json через сборку библиотеки runtime; результаты помещаются в `.local/tests/vsto`.

Harness компилирует настоящий `src/Aperture.Excel/ChatPaneControl.cs` вместе с явно тестовыми зависимостями из `FakeDependencies.cs`. Он запускает скрытые WinForms-контролы и STA message loop; Excel, Pi, COM и модель не запускаются. Ключи и локальные настройки пользователя не читаются.

16 проверок воспроизводят Stop во время отложенного старта, конкурирующий Send во время Rebind/«Новый чат» и закрытие панели во время старта. Тестовая фабрика намеренно возвращает процесс после отмены, проверяя, что панель освободит его и не отправит отложенный запрос.

Это регрессионные проверки панели, а не подтверждение живого управления Excel. Загрузка VSTO, удаление панелей закрытых окон и работа MCP проверяются отдельным live smoke.
