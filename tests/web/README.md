# Проверка веб-интерфейса чата

`chat-view.cjs` открывает настоящие `Web/chat.html`, `chat.css` и `chat.js` в headless-браузере. WebView2 bridge заменён тестовым объектом; текст аудита и ссылки на ячейки вымышлены. Тест не запускает Excel, Pi или модель и не заменяет live smoke надстройки.

Требуются Node.js, доступный через `require('playwright')` Playwright и установленный Microsoft Edge. Playwright — внешняя тестовая зависимость, в продукт он не добавляется. Если пакет уже установлен отдельно, задайте `NODE_PATH` на каталог, содержащий пакет `playwright`.

Запуск из корня репозитория:

```powershell
node tests/web/chat-view.cjs
```

По умолчанию используется канал `msedge`. Для другого установленного Chromium-браузера задайте `APERTURE_BROWSER_EXECUTABLE` с полным путём к исполняемому файлу. Путь к репозиторию определяется по расположению скрипта, поэтому запуск из другого рабочего каталога тоже допустим.

Тест выполняет **17 проверок**: команды Send/Stop/Settings, отправка подсказки через Ctrl+Enter, блокировка действий и ввода во время работы, Markdown-таблица, скрытие приветствия, безопасный вывод HTML, отсутствие ошибок JavaScript и сетевых запросов, доступность поля ввода и отсутствие горизонтального переполнения при ширине 320 px.

Скриншоты создаются в игнорируемом `work/`:

- `chat-webview-welcome.png` — начало чата, 410 × 850.
- `chat-webview-conversation.png` — синтетическая переписка с таблицей, 410 × 850.
- `chat-webview-narrow.png` — узкая панель, 320 × 650.

Успех возвращает JSON с `passed: true` и `checks: 17`. При ошибке процесс возвращает ненулевой код и закрывает запущенный им браузер.
